# Project Plan

## Goal

Use RADARSAT Constellation Mission (RCM) Earth observation data to detect, map, and monitor environmental change over time in Canada.

## Challenge concepts

- **Detect:** identify meaningful change between observations.
- **Map:** present the location and spatial extent of detected change.
- **Monitor:** support repeatable comparison of conditions over time.

## Planned workflow

```text
EODMS / RCM
    -> Jupyter exploration
    -> preprocessing
    -> change analysis
    -> processed outputs
    -> Streamlit web prototype
```

## Current scope

The project is in its initial setup and discovery phase. The final environmental phenomenon and study area have not yet been selected. Candidate directions may be evaluated during data discovery, but none should be treated as a committed choice until recorded in the decision log.

## Near-term milestones

1. Review available RCM products and access constraints.
2. Select a tentative phenomenon, study area, and observation period.
3. Validate a small reproducible preprocessing workflow.
4. Compare candidate change-detection approaches.
5. Define processed outputs and prototype the Streamlit experience.
